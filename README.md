# social-media-assets

Public image host for **RPM Tech Solutions** and **SecuraOne** social posts.

Agents generate images, push them here, then pass a stable
`raw.githubusercontent.com` URL to Buffer drafts (Facebook / Instagram).

## Layout

- `rpm/` — RPM Tech Solutions post images
- `securaone/` — SecuraOne post images

Do **not** use Git LFS. Prefer unique filenames so scheduled Buffer posts keep working.
